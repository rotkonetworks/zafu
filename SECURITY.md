# Security

Please report a vulnerability privately, not in a public issue: open the
repository's **Security** tab and choose **Report a vulnerability**. Only the
maintainers see it.

Helpful to include: what an attacker can do, the version or commit, and how to
reproduce it. We confirm receipt, agree a fix window with you before anything
is public, and credit you in the release notes unless you prefer otherwise.

The threat model and what zafu does and does not protect against are in
[docs/src/security/threat-model.md](docs/src/security/threat-model.md).
